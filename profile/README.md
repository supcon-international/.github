## What we work on

- **Agentic Automation Toolchain** — open-source, **IEC 61131-3** compatible tools built for the agentic-programming era. Same standard as Codesys / TwinCAT / Step 7, with a fraction of the complexity.
- **AI Optimization** — replacing legacy MPC / PID + human operators with **reinforcement learning** for closed-loop optimization at the process-unit level.
- **MES & Industrial Agents** — Node-RED, MQTT, MES tooling for connected factories where AI agents are first-class users.
